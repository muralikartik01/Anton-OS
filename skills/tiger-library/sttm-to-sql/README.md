STTM-to-SQL Skill

Purpose
- Generate production-ready SQL from Source-to-Target Mapping (STTM) CSVs following NorthStar conventions.

Usage
- Provide STTM file path(s) under `dataengineering/sttm/...` and matching config JSON under `dataengineering/config/...`.
- Trigger phrase: `generate sql from sttm` or `sttm to sql`.

Location
- Skill files: `dataengineering/.github/copilot/skills/sttm-to-sql`
